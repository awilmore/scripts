# INIT_SESSION

Personal dotfiles and helper scripts for Adam, for macOS and Linux.

## Layout

- `home/`: the chezmoi source folder (`.chezmoiroot` points to it). Files use the chezmoi names, for example `dot_bashrc` becomes `~/.bashrc`.
- `home/dot_bashrc.d/`: shell functions and aliases. `common.sh` is for all systems, `Darwin.sh` is for macOS, `Linux.sh` is for Linux. On this Mac, `~/.bashrc.d/*.sh` are symlinks to these files, so an edit is live after `source`.
- `config/`, `diff/`, `keep/`, `linux/`, `prompts/`, `stress/`, `working/`: older scripts and notes.
- `keep/` is in `PATH` on the Mac and on the workspace. `keep/aws-sso` gets temporary keys for the company AWS accounts. On Linux, it logs in with `--use-device-code`. On the Mac, `/usr/local/bin/aws-sso` comes first in `PATH`.
- `keep/bastion-tunnel.sh` opens an RDP tunnel to a live Azure VM through Bastion (local port 3333). It takes a full VM resource ID or a short name such as `pay4`. For a short name, it finds the VM in group `rg-vm-live-<name>-aea` with `az vm list`. If the group has two or more VMs, it shows a list. It reads `<vm>-user` and `<vm>-pass` (or `password`) from Key Vault `live-pos-vms-<name>` and copies the password to the clipboard.
- `home/dot_aws/private_config` becomes `~/.aws/config` (the company AWS profiles). It holds no keys. The `private_` prefix makes chezmoi write a real file (mode 600), not a link, so a Docker container that mounts `~/.aws` can read it. After you edit this file, run `chezmoi apply`. After you edit `~/.aws/config`, run `chezmoi re-add`.

## Notes

- `home/dot_hammerspoon/init.lua` becomes `~/.hammerspoon/init.lua` (a chezmoi symlink, macOS only). Hammerspoon (`brew install --cask hammerspoon`) moves each new standard window of Typora (70% width, 90% height) and SmartGit (80% width, full height) to the top-right corner of the external monitor, from any start (Finder, Dock, `md`, `sgit`). Hammerspoon must have the Accessibility permission. To load a change, run `hs -c "hs.reload()"`. The `md` and `smartgit` shell functions only start the apps.
- After a change to a shell file, run `bash -n <file>` to make sure that the syntax is correct.
- `home/dot_local/bin/executable_iterm-open-click` becomes `~/.local/bin/iterm-open-click` (macOS only). iTerm2 runs it on Cmd-click (Semantic History "Always run command...", `\1 \5`). It opens URLs, and it finds a relative path in the active pane folder of the focused tmux client, then opens it with the default app. It asks every tmux server, because each iTerm2 tab has its own server (`tmuxattachsession` from bash-utils starts `tmux -L <session>`). In `dot_tmux.conf`, prefix `s` runs `tmuxpicksession` (sessions on all servers) and prefix `S` runs the old `choose-tree`. It calls `tmux -u`, because iTerm2 runs it with no UTF-8 locale and tmux then changes tabs in `-F` output to `_`. Test it with `env -i HOME=$HOME PATH=/usr/bin:/bin ITERM_OPEN_CLICK_OPENER=echo`.
- `home/dot_config/ghostty/config.ghostty` becomes `~/.config/ghostty/config.ghostty` (macOS only, a symlink). It holds the Ghostty settings ported from the iTerm2 profile (Monaco 12, colours, window size, restore at start), and Cmd+Left and Cmd+Right for the previous and next tab. If the file is new, quit and start Ghostty again, because a reload does not find a new file. Tab titles come from tmux `set-titles`. For a Ghostty client, `set-titles-string` in `dot_tmux.conf` starts with the dot in the session option `@claude_dot`, which the agent-config hook `tab-colour.sh` sets. Cmd-click in Ghostty also runs `iterm-open-click`: Hammerspoon (`ghosttyCmdClick`) changes a Cmd+click in Ghostty into an Option+click, and `dot_tmux.darwin.conf` binds `M-MouseDown1Pane` to `iterm-open-click --tmux <column> <pane folder> <hyperlink> <line>`. In that mode, the script takes the word at the column of the line (Python, wide characters use two columns) and looks in the clicked pane folder, then the home folder. In that mode, it exits 0 when it finds no file, because tmux shows a failed `run-shell` over the pane. If the focused Ghostty tab does not run tmux, Hammerspoon adds Shift in its place, so that Ghostty opens its own links. Check with `ghostty +validate-config --config-file=<file>`.
- `ta` (alias in `common.sh`) runs `tmuxattachsession` from the bash-utils repo (`~/git/vibe/bash-utils`), not from this repo. Session prefix: `it` iTerm2, `gh` Ghostty, `pc` JetBrains, `ts` other. `ta it3` attaches to `it03` from any terminal. `td` (alias for `tmuxdetachsession`, also in bash-utils) detaches the current terminal.
